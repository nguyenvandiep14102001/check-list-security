# Injection

## API dễ bị tấn công nếu

- Dữ liệu do khách hàng cung cấp không được API xác thực, lọc.
- Dữ liệu do khách hàng cung cấp được sử dụng hoặc nối vào các truy vấn SQL/NoSQL/LDAP, lệnh OS, trình phân tích cú pháp XML và Object Relational Mapping (ORM)/Object Document Mapper (ODM).
- Dữ liệu đến từ các hệ thống bên ngoài (ví dụ: integrated systems) không được API xác thực, lọc và kiểm tra.

## Yêu cầu

Để ngăn chặn việc tiêm mã độc đòi hỏi phải tách biệt dữ liệu khỏi các lệnh và truy vấn:
- Thực hiện xác thực dữ liệu bằng một thư viện duy nhất, đáng tin và được duy trì tích cực.
- Xác thực, lọc và kiểm tra tất cả dữ liệu do khách hàng cung cấp hoặc dữ liệu khác đến từ các integrated systems.
- Các ký tự đặc biệt phải được thoát bằng cú pháp cụ thể.
- Nên sử dụng API an toàn có cung cấp giao diện có tham số.
- Xác thực dữ liệu đầu vào bằng bộ lọc đủ mạnh để chỉ cho phép các giá trị hợp hệ cho mỗi tham số đầu vào.
- Xác định kiểu dữ liệu và mẫu nghiêm ngặt cho tất cả các tham số chuỗi.
